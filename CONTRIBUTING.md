# Contributing

video-hfp is in beta and is not taking outside changes yet. Pull requests will be closed
without review for now — not as a judgement on them, but because the design is still being
settled one ruling at a time and a change from outside cannot follow that.

What helps today:

- **Bug reports and device results.** An issue with the clip's facts (`clip.describe()`), the
  device profile (`optimize()` or "Measure this device"), the browser, and what the trace showed
  is the most useful thing anyone can send. A hand-off line (`used`, `late`, the relearned
  bridge) from a phone we have not measured is gold.
- **Questions about the design.** The README says why things are the way they are; where it
  does not, ask.

When the beta is over, this file will say how changes are taken. Until then, please do not
open pull requests.
